Предыдущую diagnostic.1 пользователь проверял с обычной перезагрузкой и холодным запуском. Это не заменяет проверку новых функций diagnostic.2.

## Ручной сценарий

1. Установить APK с прежней подписью через `adb install -r`, открыть mapper, дождаться ADB CONNECTED.
2. Проверить старые VPN / VK Видео / YouTube назначения.
3. Назначить KEY_WWW → Recent apps panel. Открыть несколько приложений, проверить порядок, иконки, стрелки, OK и Back.
4. Назначить KEY_LOGOFF → Sleep timer. Выбрать 30 минут, закрыть и открыть меню; проверить статус. Cancel timer должен отменить отсчёт.
5. Повторить 30 минут и дождаться сна. Проверить доступность ADB до срабатывания и статус после включения.
6. Отдельно проверить перезапуск процесса и reboot, не подменяя их принудительной остановкой через Android: force-stop имеет другие последствия для будильников.

Не публикуйте сырые dumpsys/logcat: они могут содержать личные данные. Сохранённые в этом репозитории примеры обезличены; данные конкретного устройства не включены.
